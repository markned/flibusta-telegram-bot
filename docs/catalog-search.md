# Поиск и навигация по каталогу

Поиск детерминированный, без AI и внешних поисковых сервисов. Автор определяется
по ответам Flibusta и авторскому полю найденных книг, а не только по встроенным
подсказкам известных имён. Сопоставление учитывает порядок слов и ограниченные
падежные формы; имя и отчество не заменяются произвольным совпадением фамилии.
Автор + часть названия может располагаться в разном порядке.

При совпадении имени автора и названия книги интерфейс предлагает выбор.
Кавычки явно задают поиск названия. Исправление, найденное в недавних метаданных
каталога, требует подтверждения; сохранённые подсказки сами по себе не становятся
новыми результатами поиска. Все book_id поступают из каталога.

Это не понимание произвольного смысла: «похожее на Дюну» или «что-нибудь
покороче» требуют конкретного автора/названия либо перехода к жанрам. Если источник
не отдаёт кандидатов, неизвестное имя или опечатка могут остаться нераспознанными.

## Подборки

- Telegram: кнопки «🔥 Популярное» и «📖 Жанры», команды `/popular`, `/genres`.
- Веб: ссылки на главной, `/browse`, `/browse?view=genres`.
- Популярное: `/stat/w` Flibusta, **последние 7 дней, по скачиваниям**, до 100 книг,
  исходный порядок. Это не случайная выборка и не общий рейтинг за всё время.
- Жанры: `/g`, до 400 названий и кодов. Выбор жанра открывает рекомендации
  сообщества `/rec?view=books&srcgenre=<code>`, до 100 книг первой страницы источника.
  Это подборка пользователей, а не все книги жанра и не персональные рекомендации.
- Обычные `/g/<code>` при проверке 2026-10-26 возвращали пустой основной блок;
  посторонние книги из боковой панели не подставляются.
- Веб показывает по 20 книг, Telegram использует существующие книжные сессии;
  список жанров Telegram разбит по 16 кнопок. HTML не требует JavaScript или
  современных CSS-функций.

Проверка источника 2026-10-26: недельный список — 100 книг, жанров — 275,
рекомендации detective — 50 книг. Проверялись только публичные метаданные,
файлы книг не скачивались. Эти числа не являются постоянными гарантиями.

## Ресурсы и ограничения

- Общий deadline поиска сохранён. Необязательная проверка авторов работает
  параллельно с книжным поиском и ограничена 0.75 секунды или третью deadline.
- На поисковую сессию максимум `2 + max_fallback_queries` книжных запросов,
  4 поиска авторов, 2 запроса произведений; варианты и результаты ограничены.
- Отменённая проверка прекращает запрос, если других ожидающих нет. Совместный
  запрос продолжает работать, пока нужен другому пользователю.
- Подсказки читают только последние 128 строк кэша: максимум 16 свежих публичных
  наборов до 32 KiB каждый, до 200 книг и 100 авторов. Новая таблица не нужна.
- Подборки загружаются только по запросу. SQLite TTL: топ 900 секунд, жанры 86400,
  жанровые рекомендации 3600. При сбое используется существующий ограниченный
  stale-cache с видимой датой; старый рейтинг не выдаётся за актуальный.
- Существующие ограничения доступа, rate limiting, HTTP pools и reader queue
  сохранены. Новых сервисов, production-зависимостей и фоновых планировщиков нет.

## Проверка

`make check`, `make test-search`, `make test-kindle`, `make search-quality`,
`make search-benchmark`. Unit/flow-тесты используют локальный HTML и моки
Flibusta/Telegram; сеть и скачивание книг для этих тестов не нужны.
